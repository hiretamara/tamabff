How I did it: Using Gemini to write copy for my web development projects

Published by Tamara O.

Practical copy makes web projects look better

Writing copy for web development projects is one of my least favorite things to do. I enjoy writing — about what I'm learning, about what I know, and about myself. I don't enjoy having to write fake content for mockups, and there are only so many lorem ipsums I can stand to look at.

Copy is a necessary evil as a web developer. If a project is not likely to be seen by many people, I will happily make use of placeholder text. But when I have a larger scale project with multiple pages or parts, I prefer to use actual copy that is related to the project's main purpose.

Normally I would write copy myself and create content specifically for the mockup. However, writing and editing content for a fake business or project is time-consuming.

Thank goodness for AI and writing prompts.

Getting involved with Google Gemini

I turned to Google Gemini to create simple copy for a web project I'm working on. First I threw the following prompt up to Google Gemini:

Can you come up with the copy for 6 cards for a website that detail their 6 services? The copy should follow the example below and should be realistic for actual financial planning, retirement planning, investing, estate and wealth management, etc.

The cards should be formatted like this:

  • Card 1: Comprehensive Financial Planning
  • Card 2: Retirement Income & Distribution Strategy
  • Card 3: Estate & Wealth Transfer Planning
  • Card 4: Investment Portfolio Management
  • Card 5: Proactive Tax Strategy & Optimization
  • Card 6: Risk Management & Wealth Protection

Each section includes a Card Title, Subtitle/Tagline, Card Description, Key Features List, and a Call to Action button text.

This prompt told Gemini exactly what I needed for my copy on this web project. But I still needed Gemini to provide complete cards, and to insert the copy into my existing HTML.
